# StepUp on Monad

함께 달리고, 미리 예치된 챌린지 보상을 Monad에서 받는 러닝 앱입니다.

- [챌린지 열기](https://stepup-monad.gana003.workers.dev)
- [Android APK](https://github.com/mycyi1994-hash/StepUp-Monad/releases/download/monad-testnet/StepUp-Monad.apk)
- [계약 주소](https://testnet.monadscan.com/address/0xd5d563869cA856114AF80bA3C94df99281ccF005)
- [제출용 설명·데모 순서](docs/METROPOLIS.md)

크루나 주최자가 MON 보상 풀을 만들면 러너가 목표 거리를 완주하고 보상을 청구합니다. 브라우저 GPS로 바로 참여하거나 Android에서 달린 뒤 지갑 화면의 Monad 챌린지 버튼으로 기록을 가져올 수 있습니다. 지갑 서명과 실제 체인 영수증을 사용하며, 같은 기록의 중복 지급을 막습니다.

네트워크는 Monad Testnet(10143)입니다. 테스트 토큰은 금전적 가치가 없습니다. GPS 검증기는 중앙화된 서버이며 위치 위조를 완전히 막지는 못합니다. 앱의 Google 로그인은 실제 기기에서 추가 확인이 필요합니다. 미배포 추첨 계약에 대한 구매는 비활성화했습니다.

설치·구조·실행 방법은 [영문 README](README.md), 기존 기능과 이번 개발분의 구분은 [개발 기록](docs/BUILD-RECORD.md)을 참고하세요.

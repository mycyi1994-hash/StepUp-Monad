# Build record

This repository preserves the history of the author's StepUp Android codebase. The imported baseline is e2f2e4171874d348aafdb43d03f589b766ed856a. Running, accounts, sneaker artwork, crews, Android design components and the original SUP contracts predate this adaptation; they are not claimed as new hackathon work.

Work added on 11 October 2026: Monad native-MON challenge escrow; EIP-712 running proofs; GPS validation and replay protection; a challenge website; native session handoff; separate database, verifier and attester infrastructure; Monad deployment of the rewards, sneaker, vault and EAS stack; new wallet chain settings; Android challenge entry; deployment automation and these submission materials.

Prior service credentials and original deployments were not reused as project deployments. Public chain receipts are recorded in contracts/deployments/monadTestnet.json. Existing history is retained to allow the organizers to assess build-window eligibility. Eligibility remains subject to their rules and review.

Validation results and any unverified paths are recorded in VALIDATION.md. The APK release includes its source revision.
